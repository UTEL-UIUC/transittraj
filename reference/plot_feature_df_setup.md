# Set up feature distances DF

Filters features DF down to desired limit, and checks that it meets
necessary conditions.

## Usage

``` r
plot_feature_df_setup(feature_distances, distance_lims)
```

## Arguments

- feature_distances:

  DF of features & their distances

- distance_lims:

  Vector of min & max distances

## Value

A DF of filtered & validated feature distances
