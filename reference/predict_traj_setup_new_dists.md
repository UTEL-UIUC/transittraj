# Internal function to set up dataframe for interpolating times from distances

Internal function to set up dataframe for interpolating times from
distances

## Usage

``` r
predict_traj_setup_new_dists(new_distances, trip_extremes)
```

## Arguments

- new_distances:

  new distances to interpolate at

- trip_extremes:

  DF of trip time & distance extremes

## Value

DF of trip IDs & distances to interpolate at
